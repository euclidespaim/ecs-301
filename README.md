Este repositório contém o material de apoio, exemplos de código e projetos desenvolvidos durante as aulas das disciplinas **Programação de Aplicativos** e **Desenvolvimento de Sistemas** com a turma **301** da Escola Elfrida Cristino Silva no ano de 2026.

---

## 📂 Estrutura do Repositório

### 📱 Programação de Aplicativos — `Programacao de App/`

| Pasta | Conteúdo |
|---|---|
| `0-Artefatos` | Teoria e avaliações da disciplina |
| `1-Revisao` | Revisão de HTML, CSS e JavaScript |
| `2-FetchAPI` | Consumo de APIs com `fetch` |
| `3-Objetos` | Objetos em JavaScript |
| `4-GettersSetters` | Getters e setters |
| `5-Node` | Node.js: introdução, NPM, callbacks, eventos, sistema de arquivos, módulo web e envio de e-mail |
| `6-BackEnd` | Exercícios de backend e o projeto *Operação Backend* |
| `7-FrontEnd-CICD` | Publicação de sites com integração e entrega contínua (CI/CD) |

Cada aula prática traz um ou mais sites de exemplo (`site-1`, `site-2`, …) que podem ser abertos direto no navegador.

### 🖥️ Desenvolvimento de Sistemas — `Desenvolvimento de Sistemas/`

| Pasta | Conteúdo |
|---|---|
| `0 - Artefatos e Avaliações` | Planos de aula, avaliações por trimestre e material teórico |
| `1 - Apresentação da Disciplina` | Apresentação e combinados da disciplina |
| `2 - Hardware e Processador` | Revisão de hardware e funcionamento do processador |
| `3 - Sistemas Operacionais` | Introdução a sistemas operacionais |
| `4 - Gerenciamento de Processos` | Gerenciamento de processos |
| `5 - Processos e Threads` | Processos independentes, subprocessos e threads |
| `6 - Fundamentos Git` | Controle de versão com Git e GitHub |
| `7 - Fundamentos IA` | Fundamentos de Inteligência Artificial |

## 🛠 Ferramentas Utilizadas

- **VS Code**: editor de código principal.
- **Node.js e NPM**: execução de JavaScript no servidor e gerenciamento de pacotes.
- **Git/GitHub**: versionamento de projetos e colaboração.
- **Navegadores**: Chrome/Firefox para testes e depuração.

## 🚀 Como usar este material

1. Clone o repositório:
   ```bash
   git clone https://github.com/euclidespaim/ecs-301.git
   ```
2. Navegue pelas pastas para encontrar o conteúdo de cada aula.
3. Para os exemplos em Node.js, entre na pasta da aula e rode:
   ```bash
   node nome-do-arquivo.js
   ```
4. Utilize os exemplos como base para os seus próprios desafios e tarefas.
