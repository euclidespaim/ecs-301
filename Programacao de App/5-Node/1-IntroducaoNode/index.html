Parte 1: O que é um Servidor?

Desmistificando a infraestrutura da Internet.

Hardware vs Software

O Hardware (A Máquina)

É o computador físico de alta performance que fica ligado 24h por dia em um datacenter, guardando arquivos e esperando conexões.

O Software (O Serviço)

É o programa rodando dentro dessa máquina (como o nosso script Node.js). Ele intercepta as URLs digitadas e decide o que responder.

O Ciclo de Vida HTTP

1

Request

O navegador do cliente pede uma página ou dado.

2

Verbo HTTP

O pedido define qual é a intenção da ação.

3

Response

O servidor processa e entrega o resultado final.

Parte 3: Bloqueante vs Não-Bloqueante

A grande virada de chave no rendimento do Node.js.

O Modelo Síncrono (Bloqueante)

A Fila de Espera

O atendente anota teu pedido de hambúrguer e fica parado esperando a cozinha fritar a carne. Ninguém mais avança na fila até o lanche ficar pronto.

Resultado no Terminal: Executa na ordem exata (1 → 2 → 3), travando o fluxo.

const fs = require('fs');

console.log("1. Fazer o pedido");

// O código TRAVA aqui até ler o arquivo todo
const lanche = fs.readFileSync('pedido.txt', 'utf-8');
console.log("2. Comer: " + lanche);

console.log("3. Atender próximo cliente");

O Modelo Assíncrono (Não-Bloqueante)

O Sistema de Pager / Buzzer

O atendente anota o pedido, te entrega um **Buzzer** e **já atende o próximo cliente**. Quando o lanche fica pronto, o dispositivo vibra (é a nossa **Callback**).

Resultado no Terminal: O Node pula a espera e roda: (1 → 3 → 2).

const fs = require('fs');

console.log("1. Fazer o pedido");

// Não trava! Dispara a leitura e vai para a linha 9
fs.readFile('pedido.txt', 'utf-8', (err, lanche) => {
    console.log("2. Buzzer vibrou! Comer: " + lanche);
});

console.log("3. Atender próximo cliente");

Capacidade de Resposta

Modelo Síncrono (Tradicional)
150 req/s
Modelo Assíncrono (Node.js)
1.200 req/s

Como o Node nunca fica parado esperando o disco rígido responder, ele atende muito mais requisições simultâneas.

Parte 4: Criando o Servidor

Escrevendo o código do teu primeiro software de infraestrutura.

Código Prático: server.js

O script abaixo cria um servidor completo utilizando o módulo nativo do Node:

const http = require('http');

// Cria a inteligência do servidor
const servidor = http.createServer((req, res) => {
    res.writeHead(200, {'Content-Type': 'text/plain; charset=utf-8'});
    res.end('Servidor do Paim rodando com sucesso! 🚀');
});

// Liga o servidor na porta 8081
servidor.listen(8081, () => {
    console.log('Servidor ativo em http://localhost:8081');
});

Como testar no Laboratório

  • Passo 1: Crie uma pasta e abra no VS Code.
  • Passo 2: Crie os arquivos pedido.txt e server.js.
  • Passo 3: Abra o terminal integrado do VS Code e digite: node server.js.
  • Passo 4: Abra o navegador e acesse o endereço http://localhost:8081.

Desafio Prático de Fixação

Missão para as Duplas:

  1. Modifique a porta do servidor de 8081 para 8888 e faça ele rodar novamente.
  2. Altere o texto de resposta do método res.end() para exibir o nome dos integrantes da dupla.
  3. Super Desafio: Crie um novo arquivo para testar os códigos de leitura do hambúrguer (`fs.readFile`) e observe a ordem de saída dos logs no terminal!
