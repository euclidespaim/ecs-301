Parte 1: O que é o File System?

Descobrindo o módulo nativo que nos dá acesso direto ao disco rígido.

A Analogia do Almoxarifado

No Navegador (Segurança)

Por questões de segurança, o JavaScript do navegador é proibido de mexer no seu computador. Um site não pode criar ou apagar arquivos do seu HD.

No Servidor (Node.js)

O Node.js roda direto na máquina. Ele tem um ajudante nativo chamado fs (File System), que funciona como o almoxarife: ele busca, escreve ou tritura os arquivos para você.

Por que isso muda o jogo?

A Persistência de Dados

Variáveis e arrays vivem apenas na memória RAM (temporária). Com o módulo fs, nós salvamos as informações no HD para sempre. Podemos criar históricos de pontuação de jogos, relatórios de acessos ou pequenos bancos de dados em arquivos de texto comuns.

Parte 2: Lendo Arquivos

Como trazer o conteúdo de um arquivo de texto para dentro do nosso terminal.

O Método readFile()

Para ler dados, chamamos o fs.readFile().

Ele precisa de 3 coisas fundamentais:

  • O nome do arquivo: Ex: 'pedido.txt'
  • A codificação: Sempre usamos 'utf-8' para os acentos não quebrarem.
  • A Callback: A função que vai receber o erro ou o texto quando o HD responder.

fs.readFile()

Operação Não-Bloqueante: o Node faz o pedido ao HD e continua rodando o resto do script.

Código Prático: Lendo o Pedido

Script simples para ler o arquivo que criamos nas aulas anteriores:

const fs = require('fs');

// Dispara a leitura no HD de forma assíncrona
fs.readFile('pedido.txt', 'utf-8', (err, conteudo) => {
    if (err) {
        return console.log("🚨 Erro ao ler o arquivo: " + err.message);
    }
    console.log("🍔 Conteúdo do Pedido:\\n" + conteudo);
});

Parte 3: Escrevendo Arquivos

Como fazer o Node criar documentos e salvar novos dados de forma automática.

O Método writeFile()

O método fs.writeFile() é extremamente inteligente e segue duas regras automáticas:

Se o arquivo NÃO existe

O Node cria um arquivo novo com esse nome instantaneamente na pasta e injeta o texto dentro dele.

Se o arquivo JÁ existe

O Node limpa todo o conteúdo antigo, apaga o texto velho e grava o texto novo por cima.

Código Prático: Gravando Recordes

Copia este código no VS Code para criar um registrador de pontuação de jogos:

const fs = require('fs');

const conteudo = "Jogador: Gabriel_301\\nPontuação: 9500 pontos\\nNível: Máster 🏆";

// Cria ou sobrescreve o arquivo 'highscore.txt'
fs.writeFile('highscore.txt', conteudo, 'utf-8', (err) => {
    if (err) {
        return console.log("🚨 Erro ao salvar o recorde: " + err.message);
    }
    console.log("💾 Arquivo salvo com sucesso na pasta do projeto!");
});

Parte 4: Deletando Arquivos

Como limpar a casa e remover arquivos do computador via código.

O Método unlink()

Para apagar um arquivo, o Node utiliza o método fs.unlink().

O nome "unlink" (desvincular) existe porque, no sistema de arquivos, nós removemos o link ou ponteiro que aponta para aquele espaço no disco físico.

const fs = require('fs');

// Remove o arquivo permanentemente do computador
fs.unlink('highscore.txt', (err) => {
    if (err) {
        return console.log("🚨 Arquivo não encontrado!");
    }
    console.log("🗑️ Arquivo triturado com sucesso!");
});
