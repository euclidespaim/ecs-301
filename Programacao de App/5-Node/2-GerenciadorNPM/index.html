Parte 1: O que é o NPM?

Compreender o conceito de gestão de pacotes sem complicações.

A Analogia da App Store

No Telemóvel

Nós não desenvolvemos o teclado, o maps ou a câmara do zero. Vamos no Google Play ou App Store e baixamos uma aplicação pronta a usar.

No Node.js (NPM)

O NPM é a "App Store" dos programadores. Precisamos de um gerador de PDFs, gráficos ou cores no terminal? Basta descarregar o pacote pronto.

Local vs Global: A Diferença

Instalação Local (Padrão)

O pacote fica guardado estritamente dentro da pasta do projeto atual. Se criarmos uma pasta nova, precisamos de descarregar novamente. Não interfere com outros projetos.

Instalação Global (-g)

O pacote é instalado diretamente no sistema operacional da nossa máquina. Fica disponível como um comando de terminal acessível a partir de qualquer diretório.

Parte 2: A Certidão de Nascimento

Como o Node organiza a identidade e o inventário do projeto.

O Arquivo package.json

Este arquivo funciona como o inventário ou manifesto do teu software.

Ele guarda o nome do projeto, versão, autor e, o mais importante: a lista detalhada de todas as ferramentas e pacotes externos que o teu código necessita para funcionar.

{
  "name": "projeto-da-turma-301",
  "version": "1.0.0",
  "description": "Aula Prática de NPM",
  "main": "app.js",
  "author": "Euclides Paim",
  "dependencies": {}
}

Criar o Manifesto em 1 Segundo

init

npm init -y

Este comando diz ao NPM para criar a "certidão de nascimento" do projeto instantaneamente, preenchendo todas as respostas burocráticas por defeito (yes).

$ npm init -y

Parte 3: Instalar Peças

Adicionar módulos externos à tua caixa de ferramentas.

O Comando Sagrado

Para descarregar qualquer recurso da nuvem pública do NPM, usamos a seguinte sintaxe no terminal:

$ npm install <nome-do-pacote>

Abreviação permitida em ambiente de produção: npm i <nome-do-pacote>.

A Pasta node_modules

O Contentor de Códigos

Ao instalar um pacote, o NPM cria automaticamente uma pasta chamada node_modules. É aí dentro que ficam os ficheiros de código real que descarregaste da nuvem.

Regra de Ouro: Nunca alteres nada manualmente dentro desta pasta!

Atenção ao Peso

Esta pasta cresce rapidamente porque um pacote pode depender de outros dez. É por isso que nunca a enviamos para o Git.

Prática: Terminal Colorido

Instala a versão 4 do pacote chalk (compatível com CommonJS) e personaliza as saídas:

$ npm install chalk@4
const chalk = require('chalk');

console.log(chalk.blue.bold('Olá, Turma 301! 👋'));
console.log(chalk.black.bgYellow(' AVISO: Servidor Node Ativo! '));
console.log(chalk.green('Operação concluída com sucesso. ✔'));

Manutenção de Pacotes

O que queres fazer? Comando do Terminal O que acontece por trás?
Remover uma peça npm uninstall nome-do-pacote Apaga os ficheiros de node_modules e atualiza o manifesto.
Atualizar uma peça npm update nome-do-pacote Procura por correções de bugs ou melhorias estáveis na nuvem.

Parte 4: Desafio Hacker

Escreve, instala e executa a tua própria aplicação customizada.

Desafio de Laboratório (Em Duplas)

Hackers do Terminal:

  1. Cria uma pasta chamada desafio-npm e inicia o manifesto com npm init -y.
  2. Instala o pacote de estilos rodando o comando npm install chalk@4.
  3. Cria o ficheiro index.js e escreve um script que mostre no terminal o nome dos integrantes da dupla com cores diferentes (ex: um em verde e o outro em ciano).
  4. Missão Extra: Executa a aplicação utilizando o comando node index.js e mostra o resultado no monitor ao Professor!
