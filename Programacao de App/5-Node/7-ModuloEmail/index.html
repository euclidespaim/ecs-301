O Problema do Passado (SMTP)

O Correio Antigo

No modelo SMTP clássico (Nodemailer), você precisava configurar hosts, portas (587, 465), lidar com firewalls bloqueados e selar cada envelope manualmente.

É burocrático, lento e falha muito em redes de laboratório.

Configurações de Rede

Muitas vezes o firewall da escola bloqueia portas de e-mail tradicionais.

A Revolução: Envio via API

A Entrega por Drone

No modelo de API (Resend), você não configura portas. Você aperta um botão no seu código e o "Drone" da nuvem decola e joga a mensagem no quintal do cliente.

Funciona em Qualquer Rede

Se o computador abre o Google, ele envia o e-mail. Sem erros de porta!

Parte 3: O Crachá da Nuvem

Entendendo a chave de segurança para dar ordens ao drone.

O que é uma API Key?

Para o Resend saber que você tem permissão de enviar e-mails pela conta dele, você precisa de um "Crachá Secreto":

API Key (Chave Secreta)

É uma string gigante de caracteres que funciona como senha. Ela identifica sua conta e garante que os custos (ou limites) de envio caiam no seu perfil. Nunca compartilhe sua chave!

Código: O Envio Simples

Observe como o código fica limpo e legível:

const { Resend } = require('resend');

// Instancia o drone com seu crachá
const resend = new Resend('re_sua_chave_aqui');

resend.emails.send({
  from: 'onboarding@resend.dev',
  to: 'aluno@ifc.edu.br',
  subject: 'Olá Turma 301!',
  text: 'Este e-mail foi enviado via Drone (API)!'
});

Subindo o Nível com HTML

Podemos enviar layouts profissionais usando apenas tags HTML:

resend.emails.send({
  from: 'suporte@resend.dev',
  to: 'aluno@ifc.edu.br',
  subject: 'Alerta de Sistema',
  html: `
    
Drone Ativo!

    
O seu servidor Node.js acaba de decolar.

    

    
  `
});

Segurança: O Arquivo .env

Jamais coloque sua API Key direto no arquivo principal! Use um "Cofre" chamado .env.

# Arquivo .env (O Cofre)

RESEND_KEY=re_123456789

# No seu App.js

process.env.RESEND_KEY

Isso evita que hackers roubem sua chave quando você subir o código para o GitHub.

Parte 4: Desafio Prático

Hora de colocar o Drone do Resend para voar no laboratório.

Desafio: Alerta de Invasão

Missão em Duplas:

  1. Crie uma pasta drone-email e inicie o projeto com npm init -y.
  2. Instale o módulo rodando npm install resend.
  3. Crie um script que simule um sistema de segurança. Quando executado, ele deve enviar um e-mail com o assunto "⚠️ Alerta: Novo Login Detectado".
  4. O corpo do e-mail deve ser em HTML, contendo um título vermelho e um botão de "Bloquear Acesso".
  5. Missão Extra: Mostre o e-mail chegando no dashboard do Resend para o Professor!
